## Pre-entrega Modulo 3- unidad 5
 Archivo: `SQLQueryBodegaTech.sql`
- DDL y DML en SQL: administrando el inventario de BodegaTech

Propósito del ejercicio
En el trabajo diario de un analista de datos, escribir SQL no significa solo consultar datos. Significa también crear estructuras, cargarlas con información real y mantenerlas actualizadas cuando el negocio cambia. En esta práctica vas a recorrer el ciclo completo: desde definir la arquitectura de una tabla hasta reflejar operaciones reales de stock, entendiendo en qué momento corresponde usar DDL y en cuál DML.

Contexto
Sos el administrador de base de datos de BodegaTech, una empresa distribuidora de productos tecnológicos. El sistema anterior era una planilla de Excel desorganizada y tu tarea es migrar el inventario a una base de datos SQL correctamente estructurada, cargarlo con los productos actuales y registrar las primeras operaciones del día.
